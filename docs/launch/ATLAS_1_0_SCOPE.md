# Atlas Cyberdeck 1.0 — Public Delivery Scope

**Status:** LOCKED FOR CAMPAIGN PLANNING  
**Release target:** Atlas Cyberdeck 1.0  
**Current engineering baseline:** v0.13.0-alpha

---

# Campaign Promise

Atlas Cyberdeck 1.0 will turn the existing proven Android + Ubuntu runtime foundation into a polished, documented, distribution-ready mobile Linux product.

The Kickstarter campaign is **not** funding an unproven Linux-runtime concept.

The current project already demonstrates a real Ubuntu ARM64 userspace on Android without requiring Android root.

---

# Included in the 1.0 Promise

## Android Platform

- Native Android application
- Device capability detection
- Boot / initialization experience
- Dashboard
- Linux Manager
- Files
- Settings
- Terminal
- Stable navigation and application state

## Atlas Shell

- Independent Atlas command environment
- Command registry and dispatcher
- Command history
- Aliases
- Environment variables
- Pipelines and text tools
- Persistent Atlas virtual filesystem
- `.ash` scripting
- Diagnostics
- Runtime controls
- Safety controls
- Plugin architecture foundation

## Ubuntu Linux Runtime

- Rootless Ubuntu ARM64 environment
- No Android root required
- Persistent Ubuntu RootFS
- Persistent Ubuntu shell
- Runtime start / stop lifecycle
- Android DNS synchronization
- Package management
- `apt`
- `apt-get`
- `dpkg`
- Package health validation
- Real installed-package metrics
- Real RootFS storage metrics

## Runtime Safety

- Runtime circuit breaker
- Fail-closed behavior
- Safe Mode
- Controlled Recovery Mode
- Preservation of Ubuntu RootFS and user workspace
- Restricted recovery command path
- Verified recovery before returning to NORMAL state
- Safety diagnostics and visible application state

## Product-Quality Work Funded Toward 1.0

- Broader Android compatibility validation
- Performance profiling
- Battery and storage optimization
- Terminal UX refinement
- Accessibility review
- Onboarding
- Public user documentation
- Privacy review
- Security review
- Expanded regression coverage
- Release signing
- Distribution readiness
- Issue / support workflow
- Final launch assets

---

# Explicitly Outside the 1.0 Kickstarter Promise

These remain future roadmap phases and should not be represented as guaranteed 1.0 deliverables:

- Full SSH / remote-administration suite
- Full Git workflow UI
- Workspace snapshots and restore points
- Multi-device synchronization
- Desktop edition
- Dedicated Atlas hardware
- Burner Mode
- Universal Linux-package compatibility
- Support for every Android device
- Any claim of complete desktop-Linux equivalence

---

# Campaign Scope Principle

> **Promise the product Atlas can responsibly deliver, not every idea on the roadmap.**

The campaign may discuss later phases as future direction, but reward copy, delivery estimates, and funding claims must stay within this 1.0 boundary.
