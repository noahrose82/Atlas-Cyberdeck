# Purpose

This directory contains the planning documents for the **Pre-Launch / Kickstarter Preparation phase** of Atlas Cyberdeck.

The goal of this phase is to turn a technically proven alpha build into a campaign-ready product with:

- a clear public 1.0 promise;
- a credible Kickstarter story;
- real-device visual proof;
- a defensible funding model;
- realistic reward planning;
- a launch video narrative;
- an audience-building strategy;
- transparent risks and limitations.

Atlas Cyberdeck is not being presented as an unproven idea.

The Android application, Atlas shell, Ubuntu ARM64 userspace, PRoot runtime, package workflows, runtime safety system, Safe Mode, Recovery Mode, and real-device demonstrations already exist.

The campaign is intended to fund the work required to turn that foundation into a polished **Atlas Cyberdeck 1.0** release.

**This file is the authority for campaign scope.**

# Campaign Guardrails

Atlas should not claim:

- universal Android compatibility;
- universal Linux package compatibility;
- full desktop-Linux equivalence;
- perfect security;
- "unhackable" operation;
- "military-grade" security;
- anonymous hacking capability;
- forensic erasure;
- features that belong to future roadmap phases.

Credibility is a product feature.
