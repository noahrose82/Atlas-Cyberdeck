MORE THAN A TERMINAL

One app. Two shells. Real Linux.

Atlas controls the mobile workspace. Ubuntu provides the Linux userspace. They are distinct by design.

01

ATLAS SHELL

The application environment.

Commands, diagnostics, scripts, VFS workflows, lifecycle controls, and safety state live in Atlas.

  • Independent command environment
  • Persistent virtual filesystem
  • .ash scripting
  • Runtime diagnostics
  • Linux lifecycle controls
02

UBUNTU SHELL

The Linux userspace.

Atlas hands you into a persistent Ubuntu ARM64 environment when you need real Linux tools.

  • Ubuntu 24.04.4 LTS
  • APT / APT-GET / DPKG
  • Python
  • Android DNS synchronization
  • Persistent guest files

BUILT TO FAIL SAFELY

Failure should be visible.

Atlas uses a fail-closed runtime circuit breaker. Critical failures can block normal Linux startup while preserving the workspace and guiding the user through controlled recovery.
